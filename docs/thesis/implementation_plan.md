# 实施计划

## 第一阶段：系统设计

- 明确用户场景和功能边界。
- 设计多智能体角色与协作流程。
- 设计学生画像、课程资料和练习数据结构。

## 第二阶段：后端基础能力

- 搭建 FastAPI 项目。
- 接入 HelloAgents。
- 实现课程资料导入、切分和检索。
- 实现学生记忆读写。

## 第三阶段：核心 Agent

- 实现学习规划 Agent。
- 实现知识检索 Agent。
- 实现个性化讲解 Agent。
- 实现练习生成 Agent。
- 实现作业批改 Agent。
- 实现学习反思 Agent。

## 第四阶段：前端页面

- 学习目标输入页。
- 学习计划展示页。
- 对话辅导页。
- 练习提交与批改页。
- 学生画像和学习报告页。

## 第五阶段：测试与论文

- 构造典型学习案例。
- 对比无记忆、无 RAG、完整系统三种模式。
- 撰写系统设计、实现、测试和总结。
