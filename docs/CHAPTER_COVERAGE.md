# HelloAgents 16 章能力覆盖说明

本毕设题目不是简单套用某一个案例，而是把 HelloAgents 教材中的核心能力组织成完整学习系统。

| 教材能力主题 | 在本项目中的体现 |
| --- | --- |
| Agent 基础概念 | 学习导师、规划、检索、讲解、批改等 Agent 角色设计 |
| Prompt 工程 | 各 Agent 的角色提示词、输出格式约束、评分标准提示词 |
| 上下文工程 | 学生画像、历史记忆、课程片段、当前任务动态组合 |
| 工具调用 | 搜索工具、知识库检索工具、文件解析工具、代码运行工具、评分工具 |
| RAG | 课程资料切分、向量化、召回、重排、引用来源 |
| 记忆系统 | 学生长期画像、错题本、薄弱知识点、学习偏好、阶段进度 |
| 多智能体协作 | Coordinator 调度 Planner、Retriever、Tutor、Exercise、Grading、Reflection |
| Agent 通信 | Agent 之间通过结构化状态和中间结果传递信息 |
| 规划能力 | 生成阶段学习计划、每日任务和项目里程碑 |
| 反思机制 | 根据答题表现更新学习策略和下一步推荐 |
| 评估机制 | 掌握度、正确率、引用准确率、计划完成率、反馈质量 |
| 工程化部署 | FastAPI 后端、Vue 前端、配置文件、日志、测试、数据目录 |
| 前端交互 | 学习计划面板、聊天辅导、练习工作区、记忆时间线、进度仪表盘 |
| 项目案例综合 | 形成完整的教、练、评、改闭环系统 |
| 毕业设计 | 可形成开题报告、系统设计、实现、测试与论文完整材料 |

## 建议论文题目

《融合 RAG、长期记忆与多智能体协作的个性化学习辅导系统设计与实现》

## 可验证成果

- 用户输入学习目标后，系统生成个性化学习路径。
- 用户提问时，系统能基于课程资料回答并给出引用来源。
- 系统能生成练习并根据 rubric 批改。
- 系统能记录学生薄弱点，并在下一轮学习中体现记忆。
- 系统能输出学习报告和掌握度评估。
